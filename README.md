# 기업연계 업무 인수인계

2026 기업 연계 정보교원 역량강화 프로젝트의 운영 맥락을 후임자와 AI가 이어 쓰기 위한 저장소.

**증류일: 2026-09-22. 최신 운영 상태를 실시간 조회한 문서가 아니다.** 운영 기록은 주로 8/26, 후속 교안 조사는 9/11까지 확인했다. 지난 일정의 개최·이수·보고 완료 여부는 증빙으로 갱신해야 한다.

## 처음 15분

1. [핵심 맥락](docs/BRIEF.md): 목적, 역할, 운영 원칙.
2. [현황과 다음 작업](docs/STATUS.md): 지금 확인할 일, 과거 기록의 충돌.
3. [운영 절차](docs/OPERATIONS.md): 업무별 입력 → 수행 → 완료 증빙.
4. [원자료와 접근 권한](docs/SOURCES.md): 근거를 찾는 곳, 계정 이관.

AI에는 아래 문장을 붙여 시작한다. `AGENTS.md`를 자동으로 읽지 않는 도구에도 그대로 쓸 수 있다.

> 이 저장소의 AGENTS.md와 README.md를 먼저 읽고 링크된 문서를 읽어라. 오늘 날짜와 각 기록 기준일을 구분하라. STATUS.md의 확인 항목을 바탕으로 근거 있는 현황과 미확인 사항을 나누고, 내가 바로 처리할 우선순위 3개를 제시하라. 연결된 원자료 권한이 없으면 그 한계를 명시하고 접근 가능한 자료로 초안부터 작성하라. 외부 발송·실데이터 변경은 별도 지시 전 실행하지 마라.

후임자는 운영 총괄과 업무 범위를 확인한 뒤 STATUS.md의 담당자·확인일·증빙을 갱신한다. 이후 새 작업마다 전체 대화록을 넣지 말고 해당 문서와 필요한 원자료만 AI에 제공한다. [기록 양식](docs/TEMPLATES.md)을 사용한다.

## 포함 범위

핵심 업무 지식과 원자료를 요청할 때 사용할 파일명만 포함한다. 참가자 명단·전화번호·응답 원본·인증키·실발송 로그·개인 PC 경로·기존 실행 스크립트는 포함하지 않는다. 실행 도구의 이관은 별도 절차이며 이 저장소만으로 문자 발송이나 시스템 운영이 활성화되지 않는다.

이 저장소는 **공개용 인수인계 문서**다. 담당자 실명·내부 링크·사업비·참여 및 만족도 수치는 제외했다. 후임자는 운영 총괄에게 비공개 인수인계 부록과 원자료 접근 권한을 별도로 받아야 한다. 실제 업무 상태를 갱신할 때도 내부 정보는 공개 커밋에 넣지 않는다. `SOURCE_MANIFEST.json`은 증류에 사용한 로컬 파일의 경로·해시이며 원문 사본은 아니다.
