## 자료를 읽는 기준

- **기록:** 보유한 회의·계획·운영 자료에 있는 내용. 현재 실행·변경 여부까지 검증한 뜻은 아닙니다.
- **기존 초안:** 인계 전 이미 작성된 구체적인 운영 설계. 후임자가 채택·수정할 출발점입니다.
- **편집 제안:** 이번에 활동 시간·주별 진도·평가 문항을 보완한 내용. 기존 승인 사항으로 보고하지 않습니다.

정리 기준일은 2026-09-22입니다. 마지막 운영 맥락은 주로 8월, 교안 조사는 9/11입니다. 교안·양식은 이 저장소에 담았으며, 참가자 명단·실명 연락처·인증키·실적 원자료는 별도로 권한을 받아야 합니다. 안내 문안의 실제 발송과 최종 이수 판정은 최신 승인 기준을 확인합니다.

## AI에 그대로 주는 요청

> AGENTS.md, docs/SCHEDULE.md, docs/CURRICULUM.md, docs/PRELIMINARY.md를 읽어라. 저장소에 담긴 내용으로 예선 운영 계획을 작성하라. 기존 기록·기존 초안·네가 보완한 제안을 구분하고, 팀별 활동·소요시간·제출물·멘토 개입·담당 업무가 있는 표로 만들어라. 9/7~10/11 기간 중 이미 지난 일정은 현재 팀별 진도를 확인해 재편하라. 원자료가 없다는 이유로 전체 설계를 멈추지 말고, 확정이 필요한 값만 마지막에 모아라.

본선을 준비할 때는 FINAL.md와 WORKSHEETS.md를 추가하면 됩니다. [검토 이력](docs/REVIEW.md)은 참고용이고 교육·운영 설계의 필수 선행 문서는 아닙니다.
