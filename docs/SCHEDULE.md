# 전체 일정표

**기준: 2026-09-22 / 모든 시각 한국시간(KST).** 아래 ‘기록’은 마지막 보유 자료의 일정이며 실제 개최·승인 완료 여부는 구분한다. 교육 설계에는 그대로 출발점으로 쓰되 대외 재공지는 현재 담당 일정표와 대조한다.

## 사업의 흐름

집합연수에서 개인 도구를 연습 → 기업 세션에서 현업 관점 보강 → 예선에서 팀 문제와 도구를 개발 → 본선에서 사용자 피드백·개선·발표 → 학교 적용·사례집·결과보고.

기업 탐방은 당시 안내에서 **선택 참여이며 연수 이수에 영향을 주지 않는 프로그램**으로 설명했다. 집합·예선·본선은 연결되지만 각 활동 시간을 모두 합쳐 공식 이수시간으로 쓰지 않는다. 당시 LMS 등록 기록은 집합 900분 + 본선 480분 = 1,380분이며 예선은 별도 온라인 활동 12시간으로 설계했다.
