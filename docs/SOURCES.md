# 원자료와 접근 권한

공개 저장소에는 사내 문서 URL·문서 ID·개인 연락처를 싣지 않는다. 후임자는 운영 총괄에게 아래 보관처의 접근 권한과 비공개 링크 목록을 요청한다.

| 보관처 | 요청할 자료 |
|---|---|
| 사업 Drive | 계획·협약·심의·예산·운영·결과·정산 원본 |
| 사업 Slack 채널 | 결정·승인·변경·현장 보고 및 9월 보고 요청 스레드 |
| 정례 회의록 | 컨소시엄 결정사항 |
| 커리큘럼 저장소 | 계획·차시별 자료·진행 대본 |
| 신청 응답 시트 | 비공개 명단·기수·출석 |
| 연수원 LMS 및 관리자 | 수강신청·이수 대조. 후임 ID·IP 등록 요건 |

## 원자료를 요청할 때 쓸 경로

아래 경로는 **기존 담당자의 industry-linked 작업 폴더 기준**이다. 이 인수인계 저장소에 파일이 존재한다는 뜻이 아니다. 원문이 필요하면 기존 담당자에게 해당 경로를 지정해 안전한 Drive 보관처로 이관받는다. 파일 해시는 SOURCE_MANIFEST.json에서 확인한다.

## 권한 이관 완료 기준

- 관련 업무 저장소 읽기/쓰기, Drive 사업 폴더, Slack 채널, LMS 관리자 접근을 후임 계정으로 확인한다.
- Codle·짓다의 운영자/행사/결과물 권한과 Discord 서버 관리 역할을 확인한다.
- 뿌리오의 발신번호·등록 IP·인증 정보 및 기존 로그 보관처를 관리자와 이관한다.
- 인증키는 회사 비밀정보 관리 경로로 전달한다. 개인 계정이나 토큰을 README에 기록하지 않는다.
- 카카오톡·전화·메일 CS와 현장 담당, 승인 창구를 지정한다. 이 문서는 역할 위임 자체를 대신하지 않는다.
