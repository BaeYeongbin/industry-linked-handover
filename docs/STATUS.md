## 수치 해석 원칙

- 1일차 서명, 2일차 서명, 최종 이수 인원을 구분한다. 정확한 집계는 비공개 출석 원자료에서 확인한다.
- 만족도는 응답 수·문항·분모·목표 기준을 함께 확인한다. 내부 집계 수치는 공개 저장소에 기록하지 않는다.
- 탐방의 응답자 수와 복수 회차 선택 수, 실제 참석 수를 구분한다.
- 모집 목표·정원·실참·이수 실적을 구분한다. 계획값을 확보 실적으로 기재하지 않는다.
