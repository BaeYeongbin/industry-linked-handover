# AI 작업과 기록 양식

## 다음 업무를 맡길 때

> AGENTS.md를 읽고 [업무명]을 진행해라. 입력은 [원자료 링크/파일], 결과물은 [문안/대조표/보고서], 기한은 [날짜]다. 관련 STATUS 항목의 현재 근거부터 확인하고 초안과 미확인 항목을 작성해라. 발송·실데이터 변경은 아직 요청하지 않는다.

## 새 기록 반영

> 아래 회의/승인 기록에서 기존 결정의 변경과 새 할 일을 추출해라. 각 항목에 사실/제안/미확인을 구분하고 근거·날짜를 붙여 STATUS를 수정하고 DECISIONS에 이력을 추가해라. 참가자 개인정보와 비밀정보는 저장하지 마라.

## 작업 카드

- 업무 / 담당 / 기한:
- 상태: 미확인 · 진행 · 승인 대기 · 완료
- 기준일 / 원자료 링크:
- 입력 / 만들어야 할 산출물:
- 승인 필요 항목 / 승인 근거:
- 완료 증빙 / 남은 의문:

|---|---|---|---|---|---|---|

## 인수 완료 확인

- [ ] 후임과 승인 담당이 지정되었다.
- [ ] 필요한 계정으로 원자료를 열 수 있다.
- [ ] 지난 9월 행사와 현재 예선/본선 상태를 증빙으로 갱신했다.
- [ ] 미완료 업무의 담당·마감·완료 기준이 정해졌다.
- [ ] 발송/계정 자동화는 코드·권한·중복 방지 기록까지 별도 이관했다.
- [ ] 후임이 AI로 업무 초안 한 건을 작성하고 근거를 직접 찾아 검토했다.
